CÓMO REEMPLAZAR EL LOGO
========================

1. Guarda tu archivo de logo aquí (esta misma carpeta).
2. Renómbralo a:   logo.png

   (Si tu original es JPG o SVG, igual renómbralo a logo.png — funciona
    porque el HTML referencia el archivo por nombre, no por extensión real.
    Si prefieres mantener la extensión real, abre index.html y reemplaza
    "assets/logo.png" por "assets/logo.jpg" o "assets/logo.svg".)

3. Recarga el navegador (F5). Listo.

Mientras logo.png no exista, se muestra el SVG recreado (logo-mark.svg)
como fallback automático para que la web no se vea rota.

Recomendaciones del archivo:
- Formato:  PNG con fondo transparente   (ideal)
            PNG/JPG con fondo blanco     (también funciona, encaja en el cuadro blanco)
- Tamaño:   mínimo 400px de ancho, idealmente 800px+ para que se vea nítido en pantallas retina
- Si tu logo es solo el tucán sin texto, dímelo y ajusto el tamaño y agrego
  el texto "Camilo Pinilla / Psicología del Rendimiento" al lado.
